Particular · project report

Many ways a particle world can behave

Particular turns simple long-range attraction and short-range repulsion into evolving particle trails. Species rules, editable browser controls and a MAP-Elites atlas make it possible to build and explore very different worlds—from circles and pinwheels to spokes and starbursts.

What changed for users

Particles can be divided into species with asymmetric pull/push rules. Presets include classic, chase, clusters, orbit and compete; users can edit species colors and interaction matrices, save presets locally, import/export JSON, and draw or mix species. Browser coloring now respects explicit color choices when setups load.

The atlas viewer lets users navigate worlds by orderly↔chaotic, sparse↔dense and circular↔branching behavior, inspect a world's details, and load its forces and species rules into the sandbox.

Search and metric changes

MAP-Elites keeps a strong world in each reachable behavior cell rather than ranking everything by one score. The latest measurement uses trail-image behavior: heading-turn chaos, trail coverage density, and persistent radial-ray energy as a branching proxy. Fitness combines escape, large-scale symmetry, crisp detail and duration; it does not score the three axes again.

An earlier, much larger 140,000-evaluations-per-treatment run was rejected: 71% of elites lay within 0.01 of its maximum fitness, and dense cells repeated radial starbursts. It taught us that a nominally broad map and clean images do not guarantee varied results. The revised sheet looks more varied—swirling petals, pinwheels and circles in low radial-ray bins, spokes and starbursts in high bins—but the proxy is not tree topology: it undercounts curved arms and does not detect actual forks. Pinwheels still repeat in orderly cells, and some dense cells remain poor.

GPU evidence

The optional CUDA path uses a fused float64 kernel compiled through NVRTC from the torch wheel; numpy remains the reference. The earlier 2,000-evaluation-per-treatment smoke took 9 seconds on GPU versus 261 seconds on CPU. These are measured timings for that older smoke, not the final run and not a general speedup claim.

For the final atlas, all 379 renderer trajectories were bitwise identical when rerun in reversed batches of 32; rescoring reproduced every published fitness and feature exactly, with no cell changes. The GPU parity test passed. CUDA and CPU can still differ in chaotic details because floating-point summation differs.

Final search results

The final GPU run compared random sampling with MAP-Elites at 50,000 evaluations per treatment in each of 3 replicates: 300,000 scheduled evaluations. MAP-Elites reused 2,000 control starts per replicate, so it required 294,000 new simulations. Search took 514 seconds; rendering and the map sheet took about 6 seconds, for 520 seconds end to end. There were no non-finite evaluations. Of 384 possible cells, 380 were observed fillable and 379 elites are published.

Mean across replicates (random → MAP-Elites): coverage 0.923 → 0.976; reliability 0.678 → 0.917; precision 0.735 → 0.940; global performance 0.880 → 0.971. The 379 elite fitness values have 10th percentile 0.494, median 0.749, 90th percentile 0.839, and maximum 0.917; 4/379 (1.1%) are within 0.01 of the maximum. Parent→child locality was 0.76–0.80 bin widths median across replicates, versus 4.47 for random pairs; 74–75% of children landed within one cell.

Verification and limits

Final GPU parity test passed; the stored final run reports zero broken/non-finite evaluations. The exact rerender/rescore check reproduced all 379 elites' fitness and features and changed no cells. Explicit-color behavior was checked in four alternating time/species-color passes: all 28 attempted loads kept the selected mode, including 25 changed setup names and 3 clicks on the already-selected spiral; there were zero console errors. The rebuilt viewer contains 34 setups and 379 atlas worlds. All 379 baked elites matched the JSON cell, fitness, steps, pull/push and species-rule dimensions exactly. Default controls, all five axis swaps and slices, three world loads and classic reset were exercised; responsive layouts at 1280, 390 and 320px had no clipping or horizontal scroll.

The atlas is a stochastic search over a proxy aesthetic score, not a proof of visual quality. Radial-ray branching is not a tree-branch detector; chaotic trajectories and completion order can change search details. Earlier 9 s/261 s figures belong to an older smoke. A small CPU run suggests about 23 minutes for the current default settings, but that is extrapolated, not measured. This is a portable local HTML artifact, not native Claude artifact publishing.
